## How to Access

1. Clone the repository
2. Open `index.html` in a browser, or
3. Serve with HTTP server: `python -m http.server 8000`
4. Visit `http://localhost:8000`

The landing page is production-ready and can be deployed immediately to any static hosting service (GitHub Pages, Netlify, Vercel, etc.).
